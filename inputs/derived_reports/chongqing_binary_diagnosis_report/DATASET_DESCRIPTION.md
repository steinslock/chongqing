## 技术摘要

该数据集是一个青少年心理健康/精神障碍相关的受试者级多模态数据集，原始数据约 `1.5T`。数据不是单一表格，而是由临床问卷和诊断标签、EEG 脑电、fNIRS 近红外、面部视频、眼动数据以及范式/坐标附件组成。

用于健康/非健康二分类时，最清晰的主标签来自 `临床信息-重医6.3.xlsx` 中的 `诊断3-他评量表CDRS>=40`，并已在派生索引 `subject_manifest.csv` 中整理为 `primary_label_nonhealthy`：

- `0`：健康，共 `3126` 人。
- `1`：非健康/高危/疾病，共 `1372` 人。
- 空值排除：共 `112` 人，主要来自 `诊断3` 为 `-` 或 `无基线信息，排除`。

主标签下可用样本共 `4498` 人。这里的正类并不等同于单纯 MDD，而是包含高危、MDD、焦虑症、多动症、精分、强迫症、双相、PTSD 等非健康状态。因此，任务描述更准确地写作“健康 vs 非健康/高危/疾病二分类”。

## 数据使用注意事项

1. 这是受试者级数据集，训练、验证和测试必须按受试者划分。窗口、epoch、trial、帧或片段不能跨 train/test 泄漏。

2. 临床量表和诊断字段不能作为客观模态模型输入。尤其是 CDRS、CES-DC、HAMA、自杀量表、诊断列、人工复核列等，它们参与标签定义或高度近似标签，只能用于标签定义、分层描述、误差分析或临床基线对照。

3. 原始文件中存在直接身份信息。EEG 中有带姓名的主 BDF，眼动导出和工程文件中也可能含姓名、学校、采集日期等信息。派生索引和建模输入应尽量只保留 `A_id`、`L_id` 和匿名路径。

4. fNIRS 至少有两个设备来源，设备差异可能带来明显批次效应。

5. 眼动数据直接匹配样本少，姓名映射样本更多但风险更高，进入主分析前需要做冲突检查。

6. 面部视频覆盖最完整，但视频质量、有效人脸帧比例、遮挡、光照、帧率等质量控制信息需要额外提取。

7. 年龄中存在少数异常值，人口学字段进入任何分析前都需要基本清洗。

8. 主标签中的正类混合了高危和多种明确诊断。若研究问题要求“明确疾病 vs 健康”或“MDD/高危 vs 健康”，应改用对应敏感性标签，而不是直接使用主标签。
