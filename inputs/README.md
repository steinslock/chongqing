# Inputs

This directory holds project inputs that are used by the reproducible framework but are not generated by the current run.

## Layout

- `derived_reports/chongqing_binary_diagnosis_report/`: existing read-only derived dataset report bundle, including `DATASET_DESCRIPTION.md`, `data/subject_manifest.csv`, coverage summaries, QA summaries, and the original manifest-building script.

## Policy

- Treat everything under `inputs/` as read-only unless a future task explicitly asks to regenerate or repair an input bundle.
- Do not write model outputs, checkpoints, predictions, caches, logs, or temporary files here.
- Raw multimodal data stays outside this project root at `/home/qiangminc/codes/data4_qiangminc/datasets_qiangmin/chongqing`.
